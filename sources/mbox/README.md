# Mbox sources

The first four files below came from [nytpu's archive](https://nytpu.com/gemlog/2021-12-31)
([original download](https://nytpu.com/gemlog/files/gemini-mailing-list-archive.tar.gz)).

| File | Origin | Preserves original Mailman delivery order? |
| --- | --- | --- |
| `2019.mbox` | Official Mailman export for 2019, distributed by nytpu. | Yes. |
| `2020.mbox` | Official Mailman export for 2020, distributed by nytpu. | Yes. |
| `2021.mbox` | Partial official Mailman export for 2021, distributed by nytpu. | Yes, for the portion it contains. |
| `2021-nytpu.mbox` | Nytpu's personal subscriber mailbox, exported from maildir. Previously named `2021.new (adnano).mbox`. | Not trusted as Mailman's delivery sequence; used for message content and headers. |
| `2021-nervuri.mbox` | Longer official 2021 export, through June 20, [mirrored by nervuri](gemini://rawtext.club/~nervuri/gemini-archive/mailing-list/2021_incomplete.txt.gz). | Yes. Its overlapping sequence matches `2021.mbox`. |
| `adnano-complete.mbox` | Adnano's collection, [mirrored by nervuri](gemini://rawtext.club/~nervuri/gemini-archive/mailing-list/adnano_complete-archive.mbox.gz). | Not established as a complete original delivery sequence; used for message content and headers. It lacks two known 2020 emails. |

Original order includes duplicate deliveries: each consumed a Mailman message
number. Do not sort or deduplicate these inputs before reconstruction.

Both nervuri-hosted files supply the same five emails absent from the original
four files. They were downloaded compressed; the local copies are decompressed.
