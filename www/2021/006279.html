Hi Everyone

Just a quick note to announce the release of GemiNaut 0.8.11, a user friendly and idiomatic Gemini client for MS Windows.

Key new features include:

* Client certificates - create and use these to access
   sites that require them.
* Improved support for assistive technologies (e.g.
   screen readers). Such users can interactively skip over
   preformatted text regions.

Further details and downloads etc are linked from the full release announcement:
