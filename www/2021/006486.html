Hi all!

I've just completed the first usable version of a Python script called
g2ra.py.  It is a small Flask-based web application that can convert
a subscribable Gemini page to a corresponding Atom (default) or RSS
feed.

The code is at:
https://github.com/cadadr/gemini-scripts/blob/default/g2ra.py

Documentation:
https://github.com/cadadr/gemini-scripts#g2rapy

Hope it's useful to someone.

P.S: I am not experienced in deploying a service like this publically,
so I wont do that, but if someone else wants to do that, go ahead!  Any
patches are welcome.  Otherwise, it should be fairly easy to deploy
locally.
