I thought Id flag up an upcoming call for proposal for any offbeat peregrinators:

``` description
MARCH is pleased to announce our first long term inquiry, Publishing As Protocol (https://march.international/tag/publishing-as-protocol/), which aims to explore the relationship between self-organizational models and technological sovereignty. Starting with our first essay, “Trust Exercise (https://march.international/trust-exercise-stine-marie-jacobsens-group-think-rewrites-protocols-of-protest-and-consent/),” on Stine Marie Jacobsen’s project Group-Think by Jenny Wu, and unfolding through June 2022, this framework will gather together existing and speculative examples from both institutional (cultural) and technological (hacktivist) practices to reflect on how we publish, gather and organize under (and around) platform capitalism.
````
