The wormhole experiment tries to link gemini capsules.
Like ~tilde rings, but better. ^^
Want to add your capsule to the experiment?

* Add a wormhole link to your capsule. You can host one yourself or use "gemini://si3t.ch/cgi-bin/wormhole".
* Write to "prx@si3t.ch" with your capsule uri. I'll add it in my sargates list.

The code is a stupid C (or a shell script if you prefer) to call as CGI.
It reads a list of uri and redirect randomly to one of them.
