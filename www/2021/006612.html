I run my capsule (gemini://vectorprime.deszaras.xyz) from a Raspberry Pi 4 using Doppio (my own server software): https://github.com/bhavanki/doppio . Since it’s Java, as long as you can run a JVM, it will likely work.

Beyond that, though, I expect that most Gemini server implementations that run on Linux will work on a RPi, since none of them should require a lot of horsepower. Maybe try a few and see which one you like best!
